# Portfolio design

Lead with Mohammed’s name, current education, and three resume projects. Descriptions explain what each tool does and link directly to the work. Performance figures are attributed to the supplied resume; contribution counts are dated and backed by GitHub queries.

Use the shared charcoal background, warm white text, muted green links, consistent typography, and line-separated sections. Avoid decorative grids, synthetic hero diagrams, promotional scorecards, and count-up effects. Keep creative work accessible without placing every section in the main navigation.

Content renders without JavaScript. Motion is limited to short transitions; respect reduced-motion preferences. Mobile navigation and the photo viewer keep focus inside the open panel, make the background inert, close on Escape, and restore focus. Both desktop and mobile expose a resume link.

The zero-build static architecture remains. `portfolio.css` loads after the older page styles; all shared assets use versioned URLs. `resume.tex` is historical until synchronized with Mohammed’s current master PDF.

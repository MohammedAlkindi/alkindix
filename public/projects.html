2026 Developer Tools

Switchyard

Runs several coding agents against one repository without collisions. Each agent gets its own git worktree, and merges are simulated in memory first, so files that merely overlap are separated from changes that would actually conflict. On npm as @switchyardhq/switchyard, now v0.4.

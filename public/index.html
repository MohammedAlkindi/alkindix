Work

ProofX

A search engine for counterexamples in number theory. Its parallel Numba kernel checks about 21 million integers per second on two cores, roughly 200 times faster than plain Python.

Every run writes a seeded ledger, so any result replays exactly. 500 of those results are re-proved as Lean 4 theorems and checked by the Lean kernel.

Built with
Python, Numba, Lean 4
Tests
437 passing

Ridge

Spreadsheet analysis that runs the statistics in code before any AI sees the data. Correlations, Welch intervals, chi-square and KS tests are computed first, and every finding records its method, sample size and source rows.

A typical file is analyzed in under 100 ms. 565 unit and API tests plus Playwright browser tests run in CI.

Switchyard

A command-line tool for running several AI coding agents on one repository. Each agent gets its own Git worktree, and Switchyard simulates every pair's merge in memory with git merge-tree, so conflicts surface before anyone merges.

19 commands, 4 npm releases, and 260 integration tests against real repositories on Windows, macOS and Linux.

Built with
TypeScript, Node.js
Install
